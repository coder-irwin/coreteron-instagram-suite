Enterprise Operations Manual

Coreteron Instagram Suite

Autonomous registration, session verification, and real-time MXroute IMAP OTP automation.

1. Zero-Friction 1-Click Setup & Launching

The suite requires zero Git knowledge, manual virtual environment creation, or complex command line configuration. Double-click or execute the designated launcher for your operating system:

Windows PC
setup_and_run.bat

Double-click setup_and_run.bat (or Start_Windows.bat). If Python is missing, it will automatically download and install Python 3.11 with PATH enabled, install dependencies, and launch the dashboard.

Apple Mac (macOS)
Start_Mac.command

Double-click Start_Mac.command (or run ./setup_and_run.sh). It provisions dependencies, checks browser binaries, and opens your browser to http://127.0.0.1:5050.

Linux (Ubuntu/Fedora/Arch)
setup_and_run.sh

Open terminal in the folder and execute ./setup_and_run.sh. It installs required Linux browser libraries (--with-deps) and launches the local dashboard.

Default Dashboard Address: Once initialized, the dashboard automatically opens in your default web browser at http://127.0.0.1:5050.

2. Step-by-Step: Account Registration

Follow these steps to generate and register an Instagram account:

1
Open "1-Click Registration" Tab Located at the top of the left navigation menu. Form fields automatically pre-populate from your .env file.
2
Verify Mailbox & Credentials Ensure your MXroute email address (e.g. akaash_t@meenasbeautysalon.com) and mailbox password are correct.
3
Generate Randomized Profile (Optional) Click Randomize Profile to automatically generate a fresh, unique username, full name, secure password, and randomized birthday.
4
Click "Start Automated Registration" The visible browser launches and automatically enters credentials, selects the birthday, connects to MXroute to fetch the 6-digit confirmation code in under 1 second, and submits it.
5
Active Session Verification Once the confirmation code is accepted, the browser automatically verifies the session by loading the home feed and performing organic scrolls.

3. Interactive Verification Checkpoints

If Instagram presents an external challenge (such as a visual CAPTCHA or SMS verification modal):

Human-in-the-Loop Safeguard: The automation pauses execution cleanly without failing or dropping session state. An amber notification appears in the web dashboard: "Action Required: Human Verification in Browser".
  1. Switch to the visible browser window opened by the suite.
  2. Complete the required prompt (e.g., solve puzzle or submit phone challenge).
  3. Click I Solved It - Resume Automation on the web dashboard. (The system also monitors the page and automatically resumes within 3 seconds of resolution).

4. Session Login & Mailbox Diagnostics

Account Login Mode

Authenticate pre-existing accounts and verify session cookies:

  • Navigate to the Account Login tab in the navigation menu.
  • Enter your Instagram handle and password.
  • If Instagram issues a "New Device Detected" security challenge, the suite automatically accesses MXroute via IMAP, retrieves the temporary login security code, and completes sign-in.

Mailbox Connection Diagnostics

Verify IMAP connectivity before initiating registration campaigns:

  • Navigate to the Test Mailbox tab.
  • Confirm server: witcher.mxrouting.net and Port: 993.
  • Click Test IMAP Connection. The dashboard returns connection latency and total inbox message count.

5. Frequently Asked Questions & Troubleshooting

Q1: What if Python is not installed on my computer?
On Windows, setup_and_run.bat automatically detects missing Python and uses PowerShell to download and install Python 3.11 with PATH enabled. On macOS and Linux, setup_and_run.sh uses your system package manager (Homebrew, apt, dnf, or pacman). You can also install manually from python.org/downloads.
Q2: What if Instagram says "This code doesn't work. Check the code and try again"?
The engine automatically handles expired codes: it clicks the request replacement code button on Instagram, listens to MXroute IMAP for the new email, and inputs the fresh code without manual intervention.
Q3: What if Instagram flags "Username is not available"?
The engine features autonomous collision resolution: it detects the availability warning, appends randomized alphanumeric characters to the handle, and retries registration.
Q4: How do I stop or restart the suite?
Close the browser tab and press Ctrl + C in the Terminal or Command Prompt window. To restart, run your 1-click launcher again.
