Turnkey Instagram account automation with sub-second MXroute OTP verification.

1-Minute Launch (Zero Git Required)

You do not need to install Git or know any terminal commands. Simply download and extract coreteron_instagram_suite.zip, then open the file for your computer:

Apple Mac (macOS)
Start_Mac.command

Double-click Start_Mac.command. It verifies your environment and opens your browser to http://127.0.0.1:5050.

Tip for Mac: If prompted with "Unidentified Developer", simply Right-Click (or Control-Click) the file and choose Open.

Windows PC
Start_Windows.bat

Double-click Start_Windows.bat. It automatically handles the setup and opens your browser to http://127.0.0.1:5050.

Only One Prerequisite: Python 3
If you don't already have Python installed on your computer, download it from python.org/downloads. (On Windows, ensure you check the box "Add python.exe to PATH").

⚡ Step-by-Step: Creating an Account

Once the Web Dashboard opens in your browser at http://127.0.0.1:5050:

1
Go to "1-Click Registration" Tab Located at the top of the left navigation menu.
2
Fill Email Address & Mailbox Password Enter your MXroute email (e.g. user@meenasbeautysalon.com) and the mailbox password used to access incoming emails.
3
Fill or Randomize Profile Details Type your desired username and password, or click the " Randomize Profile" button to generate a clean, realistic profile in one click!
4
Click "Start Automated Registration" A visible browser window will appear. Sit back and watch the bot automatically:
  • Enter your credentials and select your birthday dropdowns
  • Connect to your mailbox and retrieve the 6-digit confirmation code in under 1 second
  • Submit the code into Instagram
  • Automatically retry if Instagram flags the code as expired
  • Scroll the home feed 3 times to confirm the active session
5
Account Verified & Ready! The dashboard displays your confirmed account details and verified status.

️ What to Do If "Confirm You're Human" Appears

Instagram security occasionally asks for a visual image check (CAPTCHA) or an SMS phone number. Our software includes Human-in-the-Loop protection:

⚠️
When A Checkpoint Appears:
1. The dashboard will show an illuminated Amber Alert Box: "Human Verification In Browser".
2. Look at the open browser window on your screen.
3. Solve the visual puzzle or enter your mobile number in the browser.
4. Click "✅ I Solved It — Resume Automation" on the dashboard (or wait 3 seconds; the bot auto-detects completion!).
5. The bot automatically resumes and finishes registration.

Diagnostic: Test Your Mailbox Connection

To avoid delays caused by mistyped email credentials, use the Test Mailbox tab to verify your connection beforehand:

  1. Click the Test Mailbox tab in the sidebar.
  2. Enter your Email Address and Mailbox Password.
  3. Click Test IMAP Connection.
  4. You will see: "✅ Success! Connected to witcher.mxrouting.net:993 with X messages" or a helpful explanation if the password was mistyped.

❓ Frequently Asked Questions (FAQ)

How do I turn off the app when I'm done?
Simply close your web browser tab, then close the Terminal or Command Prompt window (or press Ctrl + C).
Can I run multiple accounts?
Yes! You can run accounts one by one on the 1-Click Registration tab, or use the pre-built accounts_template.xlsx Excel template.
What if Instagram says "This code doesn't work"?
You do not need to do anything! The bot includes built-in self-healing: it automatically clicks "Get a new code", waits 3 seconds, reads the fresh code from your mailbox, and re-submits automatically.
What are the default MXroute server settings?
IMAP Server: witcher.mxrouting.net
Port: 993 (SSL encrypted)
